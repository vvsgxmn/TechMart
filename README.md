# 基于Spring Boot+Vue3的电脑配件商城系统

![Spring Boot](https://img.shields.io/badge/-Spring%20Boot-6DB33F?style=flat-square&logo=spring-boot&logoColor=white) ![Vue3](https://img.shields.io/badge/-Vue3-grey?style=flat-square) ![MySQL](https://img.shields.io/badge/-MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white) ![电脑配件商城](https://img.shields.io/badge/-电脑配件商城-grey?style=flat-square) 

## 项目介绍

## 项目介绍

一套完整的电脑配件商城系统，涵盖用户端商城、商家管理后台、管理员控制台三大模块，支持多角色登录与权限隔离。

## 功能模块

- **用户端商城**：商品浏览、分类筛选、搜索、商品详情、购物车、下单结算、订单管理、收货地址管理、商品评价
- **DIY装机**：自由配置台，按分类选择CPU/显卡/主板/内存等配件，实时计算预算总价，支持兼容性提示
- **AI智能装机**：基于阿里千问AI，根据预算和用途智能推荐整机配置方案
- **商家后台**：商品上架与管理、订单处理（发货/拒绝）、店铺数据统计
- **管理员后台**：仪表盘数据总览、分类管理、品牌管理、商家管理、订单管理、商品监管、用户管理
- **个人中心**：个人资料编辑、头像上传、我的装机配置保存

## 技术架构

| 层级 | 技术 |
|------|------|
| 后端框架 | Spring Boot 2.6.13 |
| 持久层 | MyBatis Plus 3.5.3 |
| 数据库 | MySQL 8.0 |
| 前端框架 | Vue 3.5 + TypeScript |
| 构建工具 | Vite 8 |
| HTTP库 | Axios |
| 认证方式 | JWT |
| AI能力 | 阿里千问 (Qwen) |
